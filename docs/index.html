Indicateur, pas un avis juridique. Les véhicules à moteur sont interdits hors des voies ouvertes à la circulation publique (art. L362-1 du code de l'environnement) ; un maire ou un préfet peut aussi fermer un chemin rural par arrêté, ce qu'aucune base ne recense : vérifier la signalisation sur place.
